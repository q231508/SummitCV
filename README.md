# SummitCV: Real-Time Object Tracking Toolkit 
This is my second computer vision project. My goal this time around was to build a flexible, reusable, and scalable tool for future use. The project uses an object oriented design, which I hope will result in less friction when adding/revisiting features.

# Setup
If you want to try out the tool:

    1. Clone the repository
        git clone https://github.com/q231508/SummitCV.git
    
    2. Move into the SummitCV directory
        cd ~/folder1/folder2/folder3/.../folder999/SummitCV

    3. Create a virtual environment
        python -m venv venv
    
    4. Activate the virutal environment
        Linux: ./venv/bin/activate
        Powershell: .\venv\Scripts\Activate
    
    5. Install requirements
        pip install -r requirements.txt
    
    6. Run the tool
        python summitcv.py [name of source window] [# tracking windows] [# colors in each mask] [optional source dimensions file]
    
    7. Calbirate tracking window size

    8. Pick colors 

    9. You're done!
